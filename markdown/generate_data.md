# 根据完整点云生成残缺点云的方法说明

本文档基于 [utils_file/perspective_render.py](/home/tianqi/corepp2/utils_file/perspective_render.py) 与 [utils_file/realtime_render.py](/home/tianqi/corepp2/utils_file/realtime_render.py) 的当前实现，总结仓库中“由完整点云生成残缺点云”的两种做法，便于论文撰写。

## 1. 总体思路

两种方法都遵循同一基本流程：

1. 输入完整点云 `P={p_i}_{i=1}^N`。
2. 随机采样一个观察视角，并将点云旋转到该视角对应的相机坐标系下。
3. 将三维点投影到二维成像平面。
4. 使用基于深度竞争的可见性判定，仅保留当前视角下能够被“相机”看到的点。
5. 从可见点中随机采样 2048 个点，作为残缺点云输出；若可见点数不足，则允许重复采样。

其核心不是直接“删除某一块区域”，而是通过模拟单视角成像过程，让遮挡关系自然决定哪些点可见、哪些点不可见，从而生成更符合真实传感器观测特点的残缺点云。

## 2. 方法一：基于正交投影的残缺点云生成

该方法实现于 [utils_file/realtime_render.py](/home/tianqi/corepp2/utils_file/realtime_render.py)，主要函数为 `partial_render_batch` 与 `ortho_render_batch`。

### 2.1 视角采样

- 方位角 `az` 在 `[0, 2π)` 内均匀随机采样。
- 俯仰角 `el` 在 `[0°, 80°]` 内随机采样。

随后构造绕 `z` 轴的方位角旋转矩阵和绕 `x` 轴的俯仰角旋转矩阵，并依次作用于输入点云，以模拟从不同方向观察物体。

### 2.2 渲染前归一化

为保证固定渲染参数对不同尺度物体都有效，代码先构造一个仅用于可见性判定的“渲染替身”点云：

1. 对每个样本减去点云质心；
2. 计算点云到质心的最大欧氏距离 `s`；
3. 将点云缩放为 `P' = (P-c)/(2s)`。

这样处理后，点云基本被限制在标准视窗范围 `[-0.5, 0.5]` 内。注意：该归一化仅用于计算遮挡关系，最终输出仍然来自原始坐标系下的点云。

### 2.3 正交投影与 Z-Buffer 可见性判定

在正交投影模型中，三维点仅使用 `(x, y)` 坐标映射到二维网格，深度由 `-z` 表示，深度值越大表示点越靠近相机。具体过程如下：

1. 将旋转后的点映射到离散二维网格；
2. 对每个像素位置，仅保留深度最大的点，形成 Z-Buffer；
3. 对 Z-Buffer 连续做两次最大池化膨胀，以填补离散点云投影时形成的小孔洞，减少背面点“漏出”的情况；
4. 对每个原始点，查询其投影像素处的前景深度，若该点深度不小于局部前景深度减去容差，则判定为可见点。

代码中使用的可见性判定可以概括为：

```text
visible(p_i) = [ depth(p_i) >= z_buffer(u_i, v_i) - tau ]
```

其中 `tau=0.15`，`(u_i, v_i)` 为点 `p_i` 的投影网格位置。

### 2.4 残缺点云生成

得到可见点集合后，从原始完整点云中取出对应可见点，并随机采样 2048 个点作为输出残缺点云。由于采样来自原始坐标，而非归一化替身，因此保留了原始物体的几何尺度与空间位置。

### 2.5 方法特点

该方法可看作一种理想化的深度成像模型：

- 不考虑透视缩放，适合快速生成单视角缺失；
- 数值稳定、显存占用较低；
- 更强调“遮挡导致的缺失”，生成结果规则、稳定；
- 适合作为训练时的大规模残缺数据合成方式。

## 3. 方法二：基于透视投影的残缺点云生成

该方法实现于 [utils_file/perspective_render.py](/home/tianqi/corepp2/utils_file/perspective_render.py)，主要函数为 `partial_render_batch_perspective` 与 `perspective_render_batch`。

### 3.1 视角采样

与正交版本相比，该实现更接近“相机围绕物体水平观察”的设定：

- 方位角 `az` 在 `[0, 2π)` 内均匀随机采样；
- 俯仰角固定为 `0°`。

也就是说，相机主要在水平方向绕物体旋转，而不显式引入仰视或俯视变化。代码中保留了加入微小俯仰扰动的注释接口，但当前实现未启用。

### 3.2 渲染前归一化与视点偏移

透视版本同样先对点云做中心化和尺度归一化，使其最大半径约为 `0.5`。这样做的原因是：透视相机的参数（如 `camera_dist`、可见性偏置和深度厚度阈值）是在标准化物体尺度上调好的，若直接对原始毫米尺度点云渲染，固定相机距离会导致相机“进入”物体内部，破坏遮挡关系。

此外，该实现支持一个额外的 `view_offset=[dx, dy, dz]` 参数。它只在渲染判定时平移归一化后的替身点云，用于改变相机对焦中心；最终输出点云仍从原始坐标中采样，因此不会真的改变物体坐标。

### 3.3 透视投影模型

透视投影中，相机位于物体前方，采用针孔成像模型。设旋转后点坐标为 `(x, y, z)`，相机距离为 `d`，焦距为 `f`，则：

```text
z_cam = z + d
u = f * x / z_cam + c_x
v = f * y / z_cam + c_y
```

其中焦距由视场角 `fov` 与图像分辨率共同确定：

```text
f = (resolution / 2) / tan(fov / 2)
```

只有满足 `z_cam > 0.1` 且投影落在图像边界内的点，才进入后续可见性判定。

### 3.4 基于 Z-Buffer 的遮挡判定

与正交投影类似，透视版本同样为每个像素构建 Z-Buffer，但此时使用的是相机坐标系深度 `z_cam`。为保持“越近越大”的比较方式，代码令：

```text
depth = -z_cam
```

随后：

1. 对每个像素取最大 `depth`，得到最靠近相机的前景表面；
2. 对 Z-Buffer 连续执行两次 `5×5` 最大池化膨胀，以扩大前景遮挡区域，抑制由于点云稀疏造成的背面穿透；
3. 用偏置 `bias=0.05` 判断点是否与当前像素处前景深度一致，若一致则视为未被遮挡。

### 3.5 深度切片约束

透视版本比正交版本多了一步“深度切片（depth slicing）”约束。其目的是模拟近距离传感器只观察到物体最外层表皮的效果。

具体做法是：

1. 在当前视锥内找到距离相机最近的点，对应最大 `depth`；
2. 设置厚度阈值 `thickness_threshold=1.5`；
3. 仅保留深度位于“最近表面之后一定厚度范围内”的点。

因此，最终可见性由三部分共同决定：

```text
is_visible = is_visible_zbuffer AND is_in_focus AND in_view
```

其中：

- `is_visible_zbuffer` 表示未被前景遮挡；
- `is_in_focus` 表示位于最近表面后的有限深度带内；
- `in_view` 表示点位于相机视场内。

这一步使得生成的残缺点云更像真实近距离深度相机采集结果，即主要保留朝向相机的外层表面，而不是完整的半个物体体积。

### 3.6 残缺点云生成

透视版本同样在可见点中随机采样 2048 个点作为输出，采样对象仍是原始点云中的对应点，因此输出保留原始几何坐标。若可见点为空，则退化为直接返回原点云。

### 3.7 方法特点

该方法更接近真实深度相机的成像过程：

- 显式建模视场角与相机距离；
- 存在透视缩放效应，近处区域在图像中占比更大；
- 通过深度切片进一步模拟近距离传感器只能看到表层区域的现象；
- 更适合合成具有真实观测偏差的残缺点云。

## 4. 两种方法的主要区别

从论文表述角度，可以将两者概括为“理想化单视角缺失”与“近真实传感器观测缺失”两类生成方式：

| 项目 | 正交投影方法 | 透视投影方法 |
| --- | --- | --- |
| 实现文件 | `realtime_render.py` | `perspective_render.py` |
| 视角采样 | 随机方位角 + 随机俯仰角 | 随机方位角，俯仰角固定 |
| 投影模型 | 正交投影 | 透视投影 |
| 相机参数 | 无显式焦距/视场角 | 显式使用 `camera_dist` 与 `fov` |
| 遮挡处理 | Z-Buffer + 膨胀 | Z-Buffer + 膨胀 |
| 额外约束 | 无 | 深度切片 |
| 结果特性 | 缺失稳定、规则 | 更接近真实深度相机观测 |

## 5. 论文中可直接使用的表述建议

如果需要较正式的论文描述，可以写为：

> 为从完整点云合成残缺点云，本文采用基于可见性分析的单视角渲染策略。具体而言，首先对完整点云随机施加视角变换，并将其投影到二维成像平面；随后利用基于 Z-Buffer 的深度竞争机制判定当前视角下的可见点，仅保留未被遮挡的前景表面点；最后从可见点集中随机采样固定数量的点，作为残缺点云输入。为提高遮挡判定的鲁棒性，本文在深度图上引入形态学膨胀操作以弥补离散点投影带来的孔洞。此外，在透视投影版本中进一步加入深度切片约束，以模拟近距离深度相机主要观测物体外层表面的特性。

如果需要区分两种实现，可以进一步写为：

> 其中，正交投影版本用于高效合成规则的单视角缺失样本；透视投影版本则显式考虑视场角、相机距离与表层深度裁剪，更接近真实深度传感器的观测机理。
